# Block 4: Streamlit UI for User Interaction

This block sets up the **Streamlit** interface that allows users to interact with the **Electronics Troubleshooting Chatbot**. Users can submit both **text descriptions** and **images** to get AI-powered diagnostics.

---

## Code

```python
# Streamlit UI
st.set_page_config(page_title="Electronics Troubleshooting Chatbot")
st.header("🔧 Conversational Image Chatbot")

# User Inputs
txt_input = st.text_input("Describe the issue or ask a question:", key="input")
uploaded_image = st.file_uploader("Upload an image (optional)", type=["png", "jpg", "jpeg"])

# Display uploaded image if any
if uploaded_image:
    st.image(uploaded_image, caption="Uploaded Image")  # Fixed: no use_container_width
    image = Image.open(uploaded_image)
else:
    image = None

# Unified submit button
submit_all = st.button("🔍 Analyze & Answer")

# Handle button click
if submit_all:
    if not txt_input and not uploaded_image:
        st.warning("Please enter a question or upload an image!")
    else:
        st.subheader("Diagnosis & Solution:")
        response = analyze_question_and_image(txt_input, image)
        st.write(response)
 ```
## Explanation
Streamlit UI Configuration : 
```python
st.set_page_config(page_title="Electronics Troubleshooting Chatbot")
st.header("onversational Image Chatbot")
```
Sets the page title and displays a header with an emoji for a friendly and intuitive interface.

User Input
Text Input: Users can describe their issue using the text input field:
```python
txt_input = st.text_input(...)
```
Image Upload: Users can optionally upload an image (PNG, JPG, JPEG):
```python
uploaded_image = st.file_uploader(...)
```
Display Uploaded Image
If an image is uploaded, it is displayed directly in the app using:

```python
st.image(uploaded_image, caption="Uploaded Image")
```
Submit Button & Input Handling
When the "Analyze & Answer" button is clicked, the app checks if at least one input (text or image) is provided.
If inputs are valid, it calls the analyze_question_and_image() function to process and display the AI-generated diagnosis and solution.
If no input is given, a warning message is shown:
```python
st.warning("Please enter a question or upload an image!")

```
## How It Works
User Interaction: Users describe their electronics problem or upload an image of the faulty component/circuit.
Input Validation : If no input is given, Streamlit shows a warning.
If valid inputs are given, the app calls the Gemini-powered analysis function.
AI Diagnosis : The response generated by Gemini is displayed under "💡 Diagnosis & Solution".

## Why This is Effective
Combines textual input and image input for multimodal troubleshooting.
User-friendly with clear warnings and visual feedback.
Uses emojis and styled headers to create an engaging user experience.
Real-time processing with Gemini ensures quick and relevant solutions.

## Dependencies
streamlit: To build the web-based UI.
Pillow (PIL): To process and display uploaded images.
Google Gemini API: For generating the AI-powered diagnostics.
